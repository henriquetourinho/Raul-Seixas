## 🇧🇷 Português

**Landing Page Homenagem Filosófica em HTML/CSS**

Este projeto é uma homenagem completa em HTML/CSS pura dedicada à vida e obra do Profeta do Rock Brasileiro, **Raul Seixas**. O design foi meticulosamente criado para refletir sua estética clássica de rock, combinada com sua profunda filosofia mística.

### 🔥 Principais Funcionalidades

  - **🎸 Discografia Completa:** Todos os 13 álbuns de estúdio com descrições únicas e filosóficas escritas na "voz" do artista.
  - **📜 O Manifesto:** Seção dedicada ao manifesto da **Sociedade Alternativa** ("O Reino de Kapper"), com design imersivo e unificado.
  - **🎨 Design Imersivo:** Tema escuro unificado com detalhes dourados, utilizando fontes clássicas ('Rye' para títulos de rock, 'Cinzel' para citações místicas).
  - **🔗 Links Diretos:** Todos os cards de álbum incluem links diretos para ouvir o disco completo nas plataformas de streaming (links de YouTube Music).
  - **🖼️ Fundos Fixos:** Utiliza o efeito Parallax do CSS com fotos icônicas de Raul nas seções biográficas.

### 📦 Instalação e Uso

Esta é uma landing page estática construída com HTML e CSS puro, exigindo **zero dependências**.

1.  **Clone o repositório:**

    ```bash
    git clone SEU_LINK_DO_REPOSITORIO
    cd nome-do-repositorio
    ```

2.  **Execute a página:**

    ```bash
    # Basta abrir o arquivo index.html no seu navegador

## 🇺🇸 English

**Philosophical HTML/CSS Tribute Landing Page**

This project is a complete HTML/CSS tribute dedicated to the life and work of Brazilian Rock Prophet, **Raul Seixas**. The design is meticulously crafted to reflect his classic rock aesthetic combined with his personal mystical philosophy.

### 🔥 Key Features

- **🎸 Complete Discography:** All 13 studio albums with unique, philosophical descriptions written in the artist's voice.
- **📜 The Manifesto:** A dedicated "O Reino de Kapper" section that acts as a manifesto for the **Sociedade Alternativa** (Alternative Society).
- **🎨 Immersive Design:** Unified dark theme with gold accents, using classic fonts ('Rye' for rock titles, 'Cinzel' for mystical quotes).
- **🔗 Direct Links:** All album cards include direct links to listen to the complete album on streaming platforms (YouTube Music).
- **🖼️ Fixed Backgrounds:** Uses CSS Parallax effects with key images of Raul in the biographical sections.

### 📦 Installation & Usage

This is a static landing page built with pure HTML and CSS, requiring **zero dependencies**.

1. **Clone the repository:**
   ```bash
   git clone SEU_LINK_DO_REPOSITORIO
   cd nome-do-repositorio
   ```

2. **Open the page:**

    ```bash
    # Just open the index file in your browser
    open index.html 
    ```
